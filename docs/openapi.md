# OpenAPI

Kokishin uses ASP.NET Core's built-in OpenAPI support to generate a machine-readable
description of its implemented HTTP API. The document is generated from the
registered endpoints and their response metadata; it is not a separate,
hand-maintained endpoint inventory.

## Access

In Development, run the API and request
[`/openapi/v1.json`](http://localhost:5108/openapi/v1.json). The development launch
profiles use port `5108`. The generated document can be used by API clients,
contract tests, and tools that accept OpenAPI JSON.

OpenAPI is not exposed by default in Production. To intentionally enable it,
set `OpenApi:ExposeInProduction` to `true`, for example with an environment
variable:

```sh
export OpenApi__ExposeInProduction=true
```

The setting defaults to `false` in `appsettings.json`. A production deployment
should enable the document only when its API discovery policy permits public
access; the generated document contains no configuration values.

## Current contract

The API always registers `GET` and `HEAD /health/database`. When authentication
is configured, it also registers authenticated `GET` and `PUT /me/profile`
operations for the caller's own profile. The profile endpoints accept no account
identifier; the account is taken from the validated principal. The generated
document describes the `200` and `503` plain-text health results, the authenticated
profile operations, and the `500 application/problem+json` response handled by
the API exception middleware.

Problem Details responses are generated by the existing ASP.NET Core error
handling. The `500` endpoint response is represented in OpenAPI. The generic
`400` validation and `404` unmatched-route responses are not responses from a
currently registered endpoint, so they are not attached to the health operation
or represented as fictional API paths.

To verify the contract, run `dotnet test Kokishin.sln`. The API integration tests
request the generated document and check the registered endpoint, methods,
response metadata, and environment-specific exposure.
