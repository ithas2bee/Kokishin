# UI Design

## Direction

Kokishin should use a familiar, practical LMS layout with forest-green branding. The goal is to make course navigation and teaching tasks easy to understand, not to copy another product's branding.

## Main layout

- A persistent left navigation sidebar on desktop
- A clear main content area
- Responsive navigation for narrower screens
- Consistent page titles, breadcrumbs where useful, and predictable action placement

## Primary navigation

- Dashboard
- Courses
- Calendar
- Inbox or messages, if included in the MVP
- Help

Navigation items should appear only when the corresponding area exists and is usable.

## Dashboard

The dashboard should prioritize the user's current courses and relevant next actions. Potential sections include course cards or a course list, upcoming assignments, recent feedback, and announcements.

## Course view

A course should present its title and status, then provide access to modules or weeks, learning pages, announcements, discussions, assignments, and grades as appropriate to the user's role.

## Visual principles

- Forest green is the primary brand color.
- Use neutral surfaces and readable text for the main content area.
- Keep the interface compact and structured, avoiding unnecessary decoration.
- Use clear visual distinctions for published, draft, submitted, and graded states.
- Provide visible keyboard focus and sufficient color contrast.
- Do not use Japanese characters, decorative Japanese motifs, or another product's logo.

## Responsive and accessible behavior

Core workflows should work with keyboard navigation and screen readers. On small screens, the sidebar may collapse into a navigation menu without hiding essential actions.
