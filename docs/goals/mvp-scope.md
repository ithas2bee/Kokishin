# MVP Scope

## MVP objective

Deliver a small, usable LMS foundation that demonstrates the core instructor and learner workflows and can grow through documented requirements.

## In scope

- User accounts and basic roles for instructor and learner
- Course creation and course overview
- Course modules or weekly units
- Learning pages and course materials
- Announcements
- Discussion activities
- Assignments and learner submissions
- Instructor feedback and basic grading
- A course grade overview
- A consistent, accessible interface for the core workflows

## Out of scope for the initial MVP

- Payments, subscriptions, or a public course marketplace
- Video conferencing built into the product
- Native mobile applications
- Complex proctoring
- Institution-wide SIS integrations
- Advanced analytics and predictive features
- AI-generated course content
- Full feature parity with commercial LMS platforms

## MVP completion criteria

The MVP is complete when an instructor can create and organize a course, publish course content and an assignment, a learner can access the course and submit work, and the instructor can review the submission and provide a grade or feedback. The main paths must be documented and tested.
